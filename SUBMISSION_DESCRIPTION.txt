This submission presents the Week 2 implementation of Echo Garden, a single-player 2D puzzle prototype based on the game concept developed in Week 1. The player controls Pip, a maintenance robot that restores water to an abandoned rooftop garden by reaching and activating water terminals.

The prototype implements the central recording and replay mechanic. Pip can record up to eight movement or wait commands, rewind to the recording position, and cooperate with an Echo that repeats those commands. The Echo can remain on a pressure plate to hold a gate open while the player travels to the terminal. Turn-based movement makes the interaction predictable and allows players to solve puzzles without time pressure.

Three playable rooms demonstrate movement, collision detection, Echo recording, synchronized replay, gate activation, level completion, and increasing route-planning complexity. The interface displays the current mode, recorded commands, turns, resets, and restored rooms. It includes hints, keyboard and button controls, a completion dialog, and a simple restoration score. Best scores are stored locally when browser storage is available.

The implementation uses HTML, CSS, and JavaScript with Canvas rendering instead of the Godot engine proposed in Week 1. The attached report explains this decision, the code structure, gameplay rules, implementation challenges, testing, limitations, and possible improvements. The source archive includes automated tests and captured results. All 17 automated tests passed during preparation. These include game-rule tests and UI integration tests using a DOM and canvas substitute; real-browser visual verification and external player testing remain separate review steps.
